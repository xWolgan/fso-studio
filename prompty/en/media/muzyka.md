# Music

## Medium: music

### Building the style description

1. **Tradition / genre** — or a deliberate absence of one. ← Music, References.
2. **Instrumentation** — specific instruments and voices (not "orchestral", but "cello, prepared piano, muted trumpet").
3. **Sound and recording** — home recording, tape, church reverb, dry booth, lo-fi, distortion.
4. **Tempo and meter** — BPM, time signature; key, if it matters.
5. **Shape over time** — how it starts, develops, ends; length. ← Time and rhythm, Editing.
6. **Vocals** — none / what kind / in what language.
7. **Mood** — last, briefly, as the result of the specifics, not instead of them.

Style tag (a short genre label) and description — separately, if the model has separate fields (see the card).

### Lyrics

- Separate from the style description, with structure markers **exactly in the syntax given in the model card** (it differs between models).
- The poem as lyrics: verbatim, uncorrected, unless the participant wants otherwise. Pronunciation and singing in the participant's language (e.g. Polish) — check in the card what the model can do.
- Music without words: mark it in a way the model understands (see the card).

### Translation rules

- **Specific instruments and production matter more than adjectives.**
- **Relationship to the image** (← Music): it leads, follows, or fights the image — this changes density, tempo and dynamics.
- **No artist names as a shortcut for style** — describe what exactly you are taking from them (← References).
- Length for a single shot or for the whole piece — settle it with the participant.
