# Voix

## Médium : voix (la voix et le texte)

Le prompt a deux parties : la **description de la voix** et le **texte à prononcer**.

### Description de la voix — matrice

1. **Situation d'enregistrement** — où, avec quoi, selon quelle convention (par ex. « interview pour un reportage radio des années 90, enregistrée dans la cour devant la maison »). Elle fixe l'acoustique et la manière de parler. ← Voix et parole, Monde et intérieurs, Temps et rythme.
2. **Qui** — sexe, âge, origine, accent (ou son absence), timbre, « appareil vocal ». ← Personnages et personnes.
3. **Texture de la voix** — enrouement, tremblement sur les voyelles allongées, souffle : concrètement.
4. **Caractère** — en une phrase.
5. **Rapport à ce qu'elle dit** — préparé ou improvisé, à qui elle parle, dans quel état elle est.
6. **Manière de parler** — tempo, pauses, trébuchements, mots de remplissage, accents soudains, respiration, raclements de gorge.

### Texte à prononcer

- La formulation exacte. Nombres, dates et abréviations : en toutes lettres.
- **La ponctuation pilote la prosodie** : virgule — courte pause ; points de suspension — suspension ; tiret — interruption ; point — chute.
- Le poème : mot pour mot, sauf si le participant veut autre chose.

### Règles de transposition

- **Série de voix** : les phrases communes (situation d'enregistrement, description d'une parole non préparée), tu les répètes mot pour mot ; tu ne fais varier que les traits de la personne.
- Longueur de la description : environ 1000 caractères a bien fonctionné (Channelers) ; vérifie la limite et le format dans la fiche modèle.
- **Clonage de voix** : le prompt, c'est le texte + un échantillon ; la description des traits agit autrement, voire pas du tout : voir la fiche.
- Une description par traits concrets, pas par jugements (« voix grave, éraillée, abîmée par la cigarette », pas « voix intéressante »).
